# 细线精密工程制图视频级排版规范 (Precision Engineering Drafting Video Vector SPEC)

本模板确立**「细线精密工程制图」（Fine-Line Precision Engineering Drafting）**为核心美学灵魂与认知载体。设计灵感汲取自**阿波罗计划航天测控图纸、德国精密工业装配蓝图（Leica / Braun）与苏黎世瑞士现代主义海报**。

**彻底抛弃 Bento Box 圆角便当盒卡片堆砌与套路化文字套娃**，恪守**“大尺度宏观实体 + 细线精密工程标定”**的第一性原理：口播负责讲，画面负责看，以大画幅工程制图图纸的威严感统领全景。

---

## 1. 核心视觉美学哲学 (Core Drafting Philosophy)

1. **宏观大气质感 vs 微观精密标定 (Monumental Hero + Precision Calibration)**：
   - 坚决杜绝“在两个小卡片内堆砌微型元器件”的微缩 CAD 陷阱。
   - 真正的工程制图美学是：**以 280px~360px 的超大尺度基础几何原型（圆、正交方框、破局冲激矢能）占据画面核心，周围由 0.75px~1.5px 的精密坐标线、尺寸引线、十字准星与等宽参数进行高精度标定**。
2. **纯粹视觉模型表达，拒绝文字层级套娃**：
   - 用**几何拓扑、正交投影、相贯透镜、临界冲激波形与遥测原语**直接呈现抽象思维；
   - 严禁堆砌副标题、双语对照、长句解释；文字仅保留核心命题大字（56px~64px 纯白粗体）与工程元数据（16px 等宽技术标注）。
3. **彻底去容器化（No Enclosing Cards）**：
   - 所有图形与尺寸线条直接在哑光黑曜石底色（`#08090C`）上自由呼吸，严禁滥用 `<rect rx="6">` 灰色容器背景。
4. **克制色彩与高信噪比工程墨水**：
   - **基底**：`#08090C` 哑光黑曜石矿物黑（吸收反光，模拟暗室光学晒图板）。
   - **结构墨水**：`#FFFFFF`（100% 纯白核心轮廓与大字）、`#8B949E`（冷钛灰工程引线与副标）、`#484F58`（暗灰刻度与基准线）、`#21262D`（极暗发丝参考网格）。
   - **单点功能标定色（只能选其一）**：
     - 琥珀黄 `#F5A623`：光学聚焦核心、奇点爆发星芒、警戒标定。
     - 测距青 `#38BDF8`：视口变换、正交扫描激光、空间坐标原点。
     - 否定红 `#E06C75`：作废划除（Strikethrough）、误差超标、阈值突破警报。

## 2. 五级物理线宽层级体系 (5-Tier Linework Architecture)

在 1920 × 1080 视频画幅中，线条粗细是构建空间进深与技术威严的第一秩序：

| 层级 | 线宽规格 (Stroke Width) | 渲染特征与样式 | 承担的工程制图语义 |
| :--- | :--- | :--- | :--- |
| **Tier 1: 发丝参考网格** | **`0.75px ~ 1.0px`** | `stroke="#21262D"` / `stroke-opacity="0.5"`<br>`stroke-dasharray="4 6"` | 隐形坐标网格、模数基准线、装配对齐虚线、极坐标经纬网 |
| **Tier 2: 尺寸引线与准星** | **`1.0px ~ 1.5px`** | `stroke="#484F58"` 或 `#8B949E"`<br>`stroke-linecap="round"` | 尺寸标注引线、十字对中准星（`+` / `⌖`）、公差带端点、切线指引 |

## 3. 六大经典工程制图视觉语汇 (Drafting Motifs)

1. **坐标十字准星与对中记号 (Center Crosshairs & Cardinal Ticks)**：
   - 元素中心或端点标注 `+`（长度 10px~20px，线宽 1px~1.5px）；
   - 圆环四周均匀分布 4 个正交向外延伸的刻度触角（Cardinal Ticks）。
2. **尺寸标注与引线系统 (Dimension Leaders & Arrows)**：
   - 两端带 45° 倾斜短划线或锐角箭头的发丝尺寸线；
   - 旁附等宽字体尺寸标注（如 `Ø 280.00`, `R 140.0`, `90° ORTHOGONAL`）。
3. **正交投影与剖切辅助虚线 (Orthogonal Projections & Datum Lines)**：
   - 从几何顶点向坐标轴投射的 1px 细虚线（`stroke-dasharray="2 3"`）；
   - 明确标示几何体的投射归属与空间坐标映射。
4. **倒角、公差带与基准面 (Chamfers & Tolerance Bands)**：
   - 矩形拐角采用 45° 切角（Chamfer `points="..."`）而非圆滑过渡，体现冷峻机械切削感；
   - 采用双平行虚线界定安全公差走廊（Tolerance Corridor）。
5. **极坐标系与辐射扇区 (Polar Ray Fans)**：
   - 从原点向外以恒定角步长（如 15° / 30°）辐射细发丝线；
   - 展现多维控制扇区与系统全景扫描。
6. **等宽技术遥测字符标头 (Monospace Telemetry Stamps)**：
   - 采用 `ui-monospace, SFMono-Regular, Menlo` 等等宽排版字体；
   - 标示工程图号、版本与状态（如 `SEC_01 // REF: DIN-476 // STG_BREAKTHROUGH`）。

## 4. 视频安全边界规范 (16:9 Video Canvas: 1920 × 1080)

视频排版受制于真人出镜与播放平台 UI，必须严格实行三域隔离：

- **左侧真人出镜遮挡区**：`x: 0 ~ 620` 严格净空，严禁任何核心几何图形入侵，为讲者抠像保留呼吸空间。
- **底部平台字幕隔离区**：`y: 920 ~ 1080` 严格净空，避免被短视频平台播放器控制栏与双语字幕遮挡。
- **主要工程图解舞台**：严格锚定在 `x: 680 ~ 1860`，`y: 100 ~ 900`（宽度 1180px，高度 800px）。

## 6. 动效与后期合成规范 (Kinetic Drafting Hooks)

在接入 HyperFrames / After Effects / GSAP 进行视听合成时，必须遵循制图物理规律：

1. **矢量路径实时绘制 (Path Drawing Growth)**：
   - 工程线条严禁生硬整体淡入；使用 `strokeDasharray` / `strokeDashoffset` 模拟针管笔或激光在图纸上实时走线绘制的过程（Duration 0.3s~0.6s，`power2.out`）。
2. **尺寸引线与刻度级联延伸 (Staggered Leaders)**：
   - 尺寸标注线、引线文字与十字准星依序以 `stagger: 0.06s` 依次点亮延伸。
3. **机械卡点吸附 (Snap to Grid Physics)**：
   - 主体图元入场终止时，必须使用高刚度阻尼弹簧（`stiffness: 280, damping: 24`），产生亚像素级微过冲后瞬间牢牢锁定在坐标网格上。
4. **奇点星芒阈值爆发 (Singularity Burst)**：
   - 核心顿悟或破局图元在经历微幅反向蓄压（Anticipation 80ms）后，以极高速度刺破边界爆发星芒，向外辐射出高亮能量射线。
