# 信息组织判断

制作时判断：本页证明什么；内容是并列、比较、因果还是层级；谁是信息主角；第一眼看哪里；关键证据和条件是否仍可读。根据实际内容与画面调整，不预先冻结坐标。以下家族是参考，不是强制枚举或逐页填表。

## 2. 页面模式

### `rational`

用于数据、分析、方法、策略、比较、建议、执行路径。

要求：

- 证据可读。
- 层级清楚。
- 信息可以快速扫描。
- 保留事实、数字、来源和限定条件。
- 不追求夸张视觉，不用复杂几何穿插替代清晰表达。
- 不把复杂内容伪装成情绪页。

### `emotional`

用于封面、章节、转场、引语、宣言、强问题页、结束页。

要求：

- 字数少。
- 单一记忆点。
- 有停顿、张力或叙事转折。
- 不承载复杂论证。
- 不牺牲可读性换取设计感。
- 在整份 deck 中只用于关键节点，通常不应占比过高。

严禁错位：不要为了好看把复杂理性页做成情绪页，也不要为了省事把需要停顿的转折页做成平庸列举页。

## 3. 反偷懒判断

模型最常见的 layout 偷懒有 6 种：

1. 把任何内容都做成三栏卡片。
2. 把两段文字放成左右两栏，却没有真实比较关系。
3. 有关键证据，却不给证据足够面积。
4. 有明显主角，却把所有内容做成等权。
5. 连续多页重复同一骨架，却没有节奏理由。
6. 文案放不下时，假装 SVG 阶段可以解决。

实际检查这些问题；不需要每页填写证明字段。

节奏提示：

- 如果连续页面节奏雷同，结合叙事判断是否调整。
- 如果多页连续使用卡片网格，只要内容允许，应引入不同组织方式。
- 长 deck 适合章节页；短 proposal 不应为了完整感硬插转场。

## 4. 版式家族索引

以下是组织逻辑索引，不是硬模板。选择 版式关系 后，必须说明本页如何适配真实文案、证据、容量和整份 deck 节奏。

### L01 - Cover / Opening Claim

用于：开启整份 deck，建立核心主题或主判断。

使用前问：

- 观众必须记住的一句话是什么？
- 辅助信息是否足够短？
- 是否需要素材区，还是只需要文字张力？

偷懒信号：封面塞进目录级信息；背景装饰和主题无关。

### L02 - Section / Transition

用于：换章、停顿、叙事转向或承诺下一段内容。

使用前问：

- 上一章节和下一章节之间发生了什么变化？
- 这是停顿、转折，还是承诺？
- 章节标题能否更短、更有记忆点？

偷懒信号：重复上一页标题；正文过多。

### L03 - KPI / Big Number

用于：少数关键数字就是主要证据。

使用前问：

- 哪个数字是主角？
- 指标之间是同级、顺序，还是共同证明一个结论？
- 是否应该用图表，而不是指标块？

偷懒信号：所有数字一样大；没有解释数字证明了什么。

### L04 - Claim + Evidence

用于：一个主判断需要截图、图表、案例、图片或数据支撑。

使用前问：

- 主判断是什么？
- 哪个证据让它可信？
- 论点和证据谁应获得更大面积？
- 证据是真实素材、占位素材，还是生成素材？

偷懒信号：旁侧视觉只是装饰；正文过长导致证据变小。

### L05 - Evidence Grid

用于：多个视觉、案例或截图共同证明一个模式。

使用前问：

- 这些证据是否同级？
- 观众应该从它们之间看见什么模式？
- 是否需要一个主证据更大？
- 图注是在解释证据，还是只贴标签？

偷懒信号：截图堆砌无解释；比例混乱像随手粘贴。

### L06 - Process / Mechanism

用于：步骤、交接、阶段、运行机制或时间顺序。

使用前问：

- 顺序是时间、运营动作，还是因果？
- 每一步发生了什么变化？
- 结果是否可见？
- 一页是否承载了太多步骤？

偷懒信号：把无序 bullet 强行塞进箭头；每一步都是空泛动词。

### L07 - Problem / Tension

用于：提出战略问题、矛盾点、悬念或转折。

使用前问：

- 希望观众感到什么张力？
- 问题是否具体，且和项目直接相关？
- 下一页是否回答这个问题？

偷懒信号：泛泛的修辞问题；视觉戏剧性没有叙事作用。

### L08 - Quote / Insight

用于：一句话本身就是页面主体。

使用前问：

- 这句话是否强到足以撑起一页？
- 是否需要署名或上下文？
- 语气应该安静、戏剧化，还是编辑感？

偷懒信号：普通总结被放大成金句页。

### L09 - Compare / Before-After

用于：两个对象、状态、策略、竞品或能力存在有意义可比性。

使用前问：

- 两侧是否等权，还是一侧应被强调？
- 比较维度是否对称？
- 这是旧/新、竞品/品牌、问题/解法，还是互补能力？
- 两侧是否都需要证据？

偷懒信号：把两段话放成两列但没有真正比较；重要性不同却默认等宽。

### L10 - Deep Explanation + Support

用于：较复杂解释需要一个辅助视觉、模型、示意图或案例支撑。

使用前问：

- 哪些内容可以移入 notes？
- 解释中哪一部分最需要视觉支撑？
- 支撑视觉是证据、机制，还是记忆装置？

偷懒信号：用小字号代替文案处理。

### L11 - Conclusion / Recommendation

用于：把前面证据收束为决策、建议、行动或下一步。

使用前问：

- 决策含义是什么？
- 建议之间是并列、顺序，还是有优先级？
- 需要结论条，还是整页本身就是结论？

偷懒信号：重复上一页；summary 变成密集复述。

### L12 - Three Pillars

用于：三个同级概念确实构成框架。

使用前问：

- 它们真的是同级支柱吗？
- 统一它们的上位逻辑是什么？
- 是否有一个需要更强强调？
- 三卡片是否对这个 deck 时刻太可预测？

偷懒信号：任意三条 bullet 被包装成三大支柱。

### L13 - Hierarchy / System Layer

用于：内容有层级、依赖、优先级或嵌套结构。

使用前问：

- 哪一层支撑哪一层？
- 层级是自上而下、自下而上，还是中心向外？
- 读者应该从哪里进入这个系统？

偷懒信号：只是为了让列表看起来更有结构而堆起来。

### L14 - Chart + Interpretation

用于：数据形态和解释同样重要。

使用前问：

- 数据洞察是什么，而不是图表类型是什么？
- 图表应占主导，还是与解读平衡？
- 哪些数据标签必须上屏？
- 哪些内容应进入 notes？

偷懒信号：图表贴上去没有解释；解读只是重复标签。

### L15 - Closing / Final Action

用于：用最终记忆点、行动或联系方式收束 deck。

使用前问：

- deck 结束后应该留下什么？
- 这是感谢页、宣言、决策页，还是下一步？
- 需要联系方式，还是只需要最终判断？

偷懒信号：泛泛的 Thank you，没有项目特异性。

### L00 - Custom

用于：L01-L15 都不能准确描述本页组织逻辑。

使用前问：

- 为什么参考家族不足以表达这页关系？
- 自定义结构的阅读路径是什么？
- 它是否能清楚表达原始事实和阅读路径？

偷懒信号：用 custom 回避说明版式选择。
