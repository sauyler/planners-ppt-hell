# 通用视觉工程与质检系统 (Style System & Visual DoD)

本文件维护跨模板成立的**排印工效、视觉力学与页面质检标准 (DoD)**。具体色值与坐标来自当前模板 SPEC.md 或视频主题，本系统负责裁决画面呈现的专业底线。

---

## 1. 核心平面设计四大基石 (C.R.A.P. Principles)

在审查任何页面时，必须逐项过目以下四大基石：

1. **对比 (Contrast)**：避免元素微弱差异。标题与正文字号比率至少拉开至 1.5 倍以上；核心焦点元素与辅助信息必须有鲜明的字重、色阶或明度反差；
2. **重复 (Repetition)**：全篇幻灯片在模块倒角、分栏间距 (Gutter 20px)、主色阶、字号阶梯上保持全局统一，贯穿始终；
3. **对齐 (Alignment)**：页面上绝不允许存在“随意摆放”的元素。所有文字与几何模块边缘必须严格吸附在 12 栏基线网格上；段落一律靠左对齐 (Ragged Right)；
4. **亲密性 (Proximity)**：位置即逻辑。彼此相关的标题与正文紧密成组，不同维度的模块之间留出足够的负空间隔断，依靠物理距离清晰表达归属。

---

## 2. 视线动线与图底分离 (Visual Ergonomics)

### 视线动线诱导 (Gutenberg Reading Gravity)
- 受众视线天然遵循自左上初级光学区滑向右下终端区的阅读重力；
- **左上角**：布置全页最高字阶的 Action Title；
- **版面中轴**：陈列核心证据、图表或主视觉；
- **右下角**：收束最终业务动作建议、数据来源或品牌 Logo 签名，完成视觉闭环。

### 图底分离与视觉进深 (Figure-Ground Segregation)
- **背景退后**：画布背景保持安静、中性的浅色或纯色底，禁止使用喧宾夺主的装饰性底纹；
- **前景坚挺**：核心文字与图形保持最高对比度前置；
- **叠印红线**：坚决禁止将数据图表或细小文字直接叠印在复杂的摄影图片纹理之上；如需压图，必须施以纯色半透明遮罩或暗角安全区。

---

## 3. 数据图表降噪工程 (Data-Ink Ratio & Zero Chartjunk)

图表绘制必须遵循 Edward Tufte 的信息设计准则：

1. **最大化数据墨水比 (Data-Ink Ratio)**：页面上的每一像素都必须直接用于呈现数据本身；
2. **处决所有图表垃圾 (Chartjunk)**：严禁使用 3D 柱体、立体饼图、渐变伪投影、莫尔条纹背景线；还原为纯净的 2D 扁平几何体；
3. **就地直接标注 (Direct Labeling)**：彻底移除远离图表的独立图例 (Legend)；将数据系列名称与具体数值直接标注在折线末端或柱体顶端，消除视线来回跳跃折耗；
4. **弱化背景网格**：网格线一律淡化为 0.5pt 浅灰或完全擦除，绝不喧宾夺主。

---

## 4. 视觉交付验收清单 (Visual DoD Checklist)

在工作台审查 PNG 预览图时，必须通过以下 6 项硬核验收：

- [ ] **焦点唯一**：全页是否存在唯一最强的第一眼焦点 (Focal Point)？是否存在多个元素平铺争抢注意力的混乱？
- [ ] **行长合规**：段落文本单行是否严控在 35 汉字内？是否存在跨越半屏的大长句？
- [ ] **边缘咬合**：相邻几何区域的上下边缘与间距是否在网格上绝对咬合？
- [ ] **图文互证**：图片是否具备清晰的物理证据能力？图表上方是否有加粗的 Takeaway Callout？
- [ ] **字阶落差**：全页字阶是否严格收拢在 3~4 个模块化梯队内（L1 Title ➔ L2 Lead-in ➔ L3 Body）？
- [ ] **无切字越界**：文字在实际容器内是否完整可读，无截断、无遮挡、无溢出？
