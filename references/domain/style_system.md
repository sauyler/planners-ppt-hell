# 页面视觉判断

本文件属于页面设计：帮助判断效果，不定义模板数值、项目画幅或技术能力。制作时先看当前视觉参考，再结合页面任务组织画面。

- **阅读层级**：第一眼能找到主旨或视觉焦点，需要细读的证据有清晰入口。密集论证与极简表达可共享同一视觉身份。
- **空间关系**：对齐、距离、尺度与图底关系服务内容。根据样张和任务选择网格、对齐及构图，保持有意图的秩序。
- **视觉连续性**：用所选主题的字体、色彩、图片处理等建立统一；各页可以使用不同骨架。
- **信息表达**：图表准确呈现比较与关系，标注便于理解；图片可承担证据或情绪表达，选取与页面目的有关的内容。
- **实际可读性**：查看渲染图中的断行、遮挡、对比和图片裁切；判断时考虑实际展示方式。技术检查通过不代表设计成立。

检查发现应指向具体页面与实际问题。配色比例、字号档数、留白面积和固定页眉不作为跨模板验收条件。技术缺陷按 [SVG 规则](svg_rules.md) 处理。
